## 제공 범위

공공데이터포털의 금융위원회 펀드 기본정보 서비스는 금융투자협회에서 수집한 펀드 상품 정보를 제공합니다. 펀드명 전체 또는 일부, 단축 코드, 분류, 펀드 유형, 기준일 범위로 조회하는 용도를 설명합니다. 펀드 식별자를 찾거나 명칭·운용사 정보를 보강할 때 출처를 확인하는 데 사용할 수 있습니다.

이 페이지는 [공공데이터포털 서비스 문서 (영문)](https://www.data.go.kr/en/data/15094792/openapi.do)와 원문이 참조하는 [서비스 명세 (영문)](https://www.data.go.kr/catalog/15094792/openapi.json)에 기반한 소개입니다. FSC 서비스에 대한 GetBeta 구현 검증이나 실제 호출 성공을 보여주는 사례는 아닙니다. GetBeta가 이 서비스를 사용한다고 주장하지 않습니다.

## 문서에 제시된 요청 형태

원문의 요청 예시는 `GetFundProductInfoService/getStandardCodeInfo` 경로에서 표준코드 정보를 조회합니다. `serviceKey`를 쿼리 매개변수로 전달하고, `pageNo`와 `numOfRows`로 페이지와 행 수를 지정하며, `resultType=json`으로 JSON 응답을 요청하는 형태입니다. `likeFndNm`은 펀드명의 일부를 사용한 검색 예시에 등장합니다.

포털에서 인코딩된 서비스 키와 디코딩된 키를 함께 보여줄 수 있으므로 사용하는 HTTP 클라이언트에 맞는 형태를 선택해야 합니다. 클라이언트가 이미 인코딩하는 값에 다시 인코딩을 적용하지 않도록 확인하세요. 이 설명에 실제 서비스 키를 넣거나 인증 요청을 실행한 것은 아닙니다.

## 응답과 기준일 다루기

문서는 JSON과 XML 응답 형태를 안내합니다. 공공데이터포털의 응답·오류 코드를 확인한 뒤 행을 처리하고, 단일 항목과 목록의 응답 형태가 같은지 실제 명세에 맞춰 확인해야 합니다. 페이지를 순회할 때도 응답의 건수와 반환 행을 대조할 수 있도록 기록하세요.

식별자 정보의 기준일인 `basDt`와 실제 수집 시각은 별도로 보관해야 합니다. 과거 펀드 기록이 존재한다는 사실만으로 지금도 같은 상품을 이용할 수 있다고 판단해서는 안 됩니다. 펀드 기본정보 조회를 실시간 NAV·가격 피드나 배당 이력 수집으로 확대 해석하지 마세요.

## 이용 조건과 확인 한계

공공데이터라는 이유만으로 실시간 갱신이나 운영 수집 성공이 보장되지는 않습니다. 이용 신청, 인증, 요금과 호출 허용량은 출처·실제 확인일이 표시된 항목에서 확인하고, 필요한 사용 조건은 공식 서비스 문서와 대조하세요.

경제통계 시계열이 필요한 경우에는 [BOK ECOS 개요](../bok-ecos/)와 [금융위원회 펀드 기본정보·BOK ECOS 비교](../../compare/fsc-data-go-kr-vs-bok-ecos/)를 참고하세요. 펀드 식별자 조회와 한국은행 통계 조회는 서로 다른 목적의 작업입니다.
