## 서비스와 검토 범위

[SEIBRO 공식 포털](https://seibro.or.kr/)과 [한국예탁결제원](https://www.ksd.or.kr/)에서 공식 서비스의 맥락을 확인할 수 있습니다. 이 개요는 증권 정보를 찾아보고 배당 수집의 완전성을 연구할 때 참고하기 위한 자료입니다. 원문 상태는 `research`이며, 운영 연동이 승인된 공개 API라는 뜻이 아닙니다.

관련 사례는 검토한 애플리케이션 어댑터와 축약된 합성 테스트를 설명합니다. 웹사이트를 브라우저로 열 수 있다는 사실만으로 인증 없는 서버 API 계약이 성립하는 것은 아닙니다. 브라우저 서비스의 동작과 필드는 운영에 사용하기 전에 별도로 확인해야 합니다.

## 공개 API 계약에서 확인하지 못한 사항

원문 검토에서는 공개 REST 기본 URL, 재사용 가능한 API 인증 방식, 버전이 명시된 공개 REST 계약을 독립적으로 확인하지 못했습니다. 공개 서버 API 요금표, 허용 요청량, 서비스 수준 보장도 확인하지 못했습니다. 웹훅 계약 역시 검증되지 않았습니다.

공식 포털은 HTTPS로 접근하는 HTML 서비스이며, 연동에 쓰이는 XML 형식은 별도 검증이 필요합니다. 이 페이지의 출처·확인일이 표시된 항목에서도 확인된 정보와 미확인 사항을 구분할 수 있습니다. 브라우저에서 관측한 요청을 안정적인 공개 REST 명세로 간주하지 마세요.

## 배당 목록과 건수 대조

검토한 연동에는 `LIST_CNT`, `START_PAGE`, `END_PAGE`가 등장합니다. 이들은 브라우저 서비스 연동에서 관측한 필드이며, 앞으로도 유지되는 공개 REST 페이지 처리 계약을 보장하지 않습니다.

[SEIBRO 세이브로 배당금 수집 범위·건수 검증 사례](../../guides/seibro-dividend-pagination-count-mismatch/)는 배당 목록의 완전성과 건수 대조를 다룹니다. 사례에서 붙인 애플리케이션의 수집 범위 오류 이름은 공급자가 정의한 오류 코드와 구분해야 합니다. 검토된 어댑터나 합성 테스트를 실제 서비스 전체 이력의 완전성 증명으로 해석해서는 안 됩니다.

## 운영 연동의 한계

운영에 연결하기 전에 서비스 운영자에게 허용되는 사용 방식, 인증, 요청 허용 범위를 확인해야 합니다. 공식 포털이라는 이유로 서버 수집 권한이나 안정적인 요청 계약이 자동으로 확보되는 것은 아닙니다. 이 개요는 승인된 공개 REST API, 검증된 요청 한도, 서비스 수준 보장을 주장하지 않습니다.

한국과 미국 배당의 출처를 나누는 구체적인 경계는 [EODHD 한국 배당 지급일 누락과 SEIBRO 시장별 수집 사례](../../guides/eodhd-seibro-korean-dividend-source-selection/)에서 확인하세요. [EODHD 개요](../eodhd/)와 [한국·미국 주식 데이터 API 선택 가이드](../../guides/choose-stock-market-data-api/)도 함께 참고할 수 있습니다.
