## 제공 범위

한국은행 ECOS는 한국은행 통계를 확인하는 기준 출처입니다. 통계표 목록 탐색, 항목 조회, 통계 관측값, 주요 지표와 공표 일정 관련 정보를 제공합니다. 통계표 코드와 항목 코드를 이용하므로 같은 계열을 다시 조회하고 수집 근거를 추적하는 데 적합합니다.

필요한 한국 경제통계 계열이 ECOS에 있다면 원천 통계의 정의부터 확인하세요. 공표 시점, 수정치, 단위, 빈도는 관측값의 의미를 구성합니다. 화면에 붙이는 부가 설명만으로 취급해서는 안 됩니다.

## 통계표와 항목을 먼저 찾기

`StatisticTableList`로 통계표를 탐색하고 `StatisticItemList`로 항목을 확인한 다음, `StatisticSearch`로 해당 시계열을 조회하는 흐름입니다. `KeyStatisticList`는 주요 통계 지표를 확인하는 서비스입니다. 선택한 통계표·항목 코드와 주기는 데이터와 함께 기록해 이후 갱신을 점검할 수 있게 하세요.

원문에 제시된 일반적인 요청 형태는 다음과 같습니다. 중괄호 안의 값은 실제 인증 정보가 아닌 자리표시자입니다.

```text
GET https://ecos.bok.or.kr/api/StatisticSearch/{API_KEY}/json/kr/1/10/{STAT_CODE}/{CYCLE}/{START}/{END}/{ITEM_CODE}
```

요청 경로에는 서비스명, API 키, 응답 형식, 언어, 시작·끝 행 번호와 통계 조회 조건이 들어갑니다. 예시의 행 번호는 요청 범위를 나타내며 서비스 호출 허용량을 뜻하지 않습니다. 응답을 읽을 때는 ECOS 결과 코드와 메시지를 먼저 확인해야 합니다. 인증과 이용 조건은 이 페이지의 출처·확인일이 있는 항목 및 [ECOS 공식 개발 안내](https://ecos.bok.or.kr/api/)를 확인하세요.

## USD/KRW 조회의 의미 확인

원문에 있는 USD/KRW 조회 예시는 통계표 `731Y001`, 일 주기 `D`, 항목 코드 `0000001`을 사용합니다. 통계표만 지정한 응답에는 여러 통화가 포함될 수 있으므로 첫 행이나 숫자의 크기로 USD라고 추정해서는 안 됩니다.

`StatisticSearch.row`의 형태, `ITEM_NAME1`, `DATA_VALUE`를 확인하고 쉼표가 포함된 값이나 결측 표시를 구분해야 합니다. 관측값을 금액으로 처리할 때는 원래 문자열의 의미를 검증한 뒤 `Decimal`로 읽는 경계를 검토하세요. [ECOS USD/KRW 통화 식별 검증 사례](../../guides/ecos-usd-currency-identity-validation/)는 항목 코드와 이름을 함께 요구하고, 누락·중복·잘못된 값을 거부하는 축약 예제를 제공합니다.

## 연동 제약과 검증 범위

통계 계열마다 공표 일정과 주기가 다릅니다. 요청한 날짜에 관측값이 없을 때 이전 관측값을 사용한다면 실제 관측일과 요청일을 구분해 보관해야 합니다. 캐시 역시 어떤 날짜와 계열의 값인지 추적할 수 있어야 하며, 결측을 새 관측값으로 표현해서는 안 됩니다.

이 제공자 개요는 원문의 문서·요청 형태를 설명합니다. 연결된 USD/KRW 사례에는 고정된 GetBeta 코드 검토와 합성 Python 예제 검사 근거가 있지만, 실제 인증 요청이나 모든 배포 경로의 수정 완료를 입증하지는 않습니다. 통계표·항목 정의와 현재 이용 조건은 공식 안내에서 다시 확인해야 합니다. 원문에서 웹훅 인터페이스는 확인되지 않았습니다.
