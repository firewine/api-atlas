## 제공 범위

EODHD(EOD Historical Data)는 하나의 좁은 피드가 아니라 여러 시장 데이터 엔드포인트를 제공합니다. EOD 엔드포인트는 일별·주별·월별 OHLCV 이력을 반환합니다. OHLCV는 시가·고가·저가·종가·거래량을 뜻합니다. 더 넓은 제품군에는 기업 기초 데이터, 배당, 주식 분할, 장중 가격, 달력, 거래소 메타데이터, 뉴스와 일부 실시간 피드가 포함됩니다.

하나의 공급자에서 여러 시장 데이터셋을 연결하려는 서비스라면 검토할 수 있습니다. 다만 엔드포인트가 존재한다는 사실만으로 필요한 거래소·필드·갱신 주기까지 보장되지는 않습니다. 실제 이용할 데이터셋을 요금제와 라이선스 조건에 맞춰 확인하세요. 가격, 호출 한도, 인증 등 계약 정보는 이 페이지의 출처와 실제 확인일이 표시된 항목에서 확인할 수 있습니다.

## 요청과 응답 처리

원문의 EOD 요청 예시는 `AAPL.US`처럼 거래소가 포함된 종목 식별자를 사용합니다. EOD 엔드포인트의 기본 응답은 CSV이며, JSON이 필요하면 `fmt=json`을 지정합니다. `api_token` 쿼리 매개변수를 사용하더라도 토큰은 서버에서 보관해야 합니다.

배당 이력을 처리할 때는 `value`, `date`, `paymentDate`, `currencyCode`의 의미와 누락 가능성을 구분하세요. 원문의 Python 예제는 금액이 없는 행을 건너뛰고 `Decimal(str(amount))`로 금액을 읽으며, 없는 `paymentDate`를 `None`으로 남깁니다. 이런 파싱 처리만으로 배당 이벤트의 완전성이나 날짜의 정확성이 확인되는 것은 아닙니다.

## 주요 엔드포인트

| 엔드포인트 | 용도 |
| --- | --- |
| `GET /api/eod/{symbol}` | 종가 기준 OHLCV 이력 |
| `GET /api/real-time/{symbol}` | 실시간 시세 |
| `GET /api/div/{symbol}` | 배당 이력 |
| `GET /api/splits/{symbol}` | 주식 분할 |
| `GET /api/fundamentals/{symbol}` | 기업 기초 데이터 |
| `GET /api/news` | 금융 뉴스 |
| `GET /api/eod-bulk-last-day/{exchange}` | 거래소별 종가 데이터 일괄 조회 |
| `GET /api/screener` | 종목 조건 검색 |

각 경로의 범위와 사용 조건은 [EODHD 공식 문서 (영문)](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes)를 확인하세요. 실시간 데이터의 거래소 범위와 이용 권한은 요금제에 따라 다를 수 있습니다.

## 연동 전에 확인할 한계

개인용 구독만으로 데이터 재배포 권리를 얻었다고 판단해서는 안 됩니다. 필요한 데이터셋마다 저장, 표시, 재배포 등 실제 용도에 적용되는 권리를 확인해야 합니다.

원문에 기록된 2026년 9~10월 관찰에서는 배당의 `paymentDate`가 `null`인 행이 있었고, 특히 한국 상장 종목에서 누락이 두드러졌습니다. 일부 행은 지급일이 배당락일보다 앞섰습니다. 지급 달력을 만들기 전에 필요한 날짜가 있는지와 날짜의 선후관계를 확인하세요. 이 관찰을 모든 종목이나 이후 모든 시점에 대한 보장으로 해석해서는 안 됩니다.

ETF 종가를 발행사의 NAV와 비교할 때도 기준 확인이 필요합니다. EOD 종가가 정규장과 시간외 중 어느 세션을 따르는지, 주거래소와 통합 시세 중 어느 기준인지가 원문 검토에서 충분히 문서화되지 않았습니다. 특정 상장 종목의 `isPrimary` 의미도 모호한 것으로 기록되어 있습니다. 서비스가 의존하는 필드를 다른 출처와 대조하고 산출 기준을 확인한 뒤 사용하세요.
