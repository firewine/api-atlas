## 조회 목적부터 구분하기

공공데이터포털의 금융위원회 서비스는 펀드 상품의 이름, 표준코드, 운용사, 분류, 유형, 기준일을 다룹니다. BOK ECOS는 통화·금융·물가·국민계정 등 한국 경제통계 시계열을 조회하는 서비스입니다. 어느 서비스가 더 넓은 기능을 갖췄는지보다 필요한 결과가 식별자 정보인지 통계 관측값인지 먼저 정해야 합니다.

| 선택 기준 | 금융위원회 펀드 기본정보 | BOK ECOS |
| --- | --- | --- |
| 주요 데이터 | 펀드명, 표준코드, 운용사, 분류, 유형 | 여러 통계표의 한국 경제통계 시계열 |
| 탐색 흐름 | 펀드명·단축 코드·유형·기준일 조건으로 조회 | 통계표 목록과 항목 목록을 찾은 뒤 관측값 조회 |
| 인증 형태 | 쿼리 매개변수 `serviceKey` | 요청 경로에 포함되는 ECOS API 키 |
| 요청 범위 | `pageNo`·`numOfRows` | 경로에 포함되는 시작·끝 행 번호 |
| 응답 형식 | JSON·XML | JSON·XML |
| 날짜 확인 | 정보의 `basDt`와 수집 시각 | 관측일, 계열 주기, 공표 시점과 수정치 |

이 비교는 원문이 참조한 서비스 문서의 범위를 설명합니다. 요금, 이용 신청, 호출 허용량 등 변동 가능한 조건은 [금융위원회 제공자 개요](../../apis/fsc-data-go-kr/)와 [BOK ECOS 제공자 개요](../../apis/bok-ecos/)의 출처·확인일이 있는 항목에서 확인하세요.

## 펀드 식별자를 확인할 때

한국 펀드의 이름, 표준코드, 운용사를 대응시키거나 정보를 보강하려는 목적이라면 금융위원회 펀드 기본정보 서비스의 데이터 범위가 맞습니다. 원문은 금융투자협회에서 수집한 공식 식별자 정보와 조건 조회를 설명합니다.

이것은 서비스 문서 검토에 기반한 역할 설명이며, FSC API의 실제 응답이나 GetBeta 운영 연동을 검증한 결과가 아닙니다. 펀드 기록을 실시간 NAV·가격이나 배당 이력으로 간주해서는 안 됩니다. `basDt`와 수집 시각을 분리하고 과거 기록만으로 현재 이용 가능성을 추정하지 마세요.

## 경제통계 시계열을 조회할 때

한국은행 통계가 필요하면 ECOS에서 통계표·항목 코드를 먼저 확인합니다. 코드를 보관하면 같은 계열을 재조회하고 출처를 추적할 수 있습니다. 통계표, 항목, 주기 값은 조회 전에 확인할 조건이며 그럴듯한 이름이나 수치로 대체할 수 없습니다.

[ECOS USD/KRW 통화 식별 검증 사례](../../guides/ecos-usd-currency-identity-validation/)는 응답이 정상 JSON이어도 다른 통화의 값을 고를 수 있는 문제를 설명합니다. 이 사례에는 고정된 GetBeta 코드 검토와 합성 예제 검사 근거가 있습니다. 그것이 실제 인증 API 호출이나 모든 배포 경로의 수정 완료를 입증하는 것은 아닙니다.

## 비교의 한계

이 문서의 서비스 역할 비교, 사례의 구현 소스 검토, 합성 입력 검사, 실제 공급자 호출은 각각 다른 확인 범위입니다. FSC에는 문서 기반 소개를 넘는 GetBeta 사용 주장을 하지 않으며, ECOS 사례의 합성 결과를 실측 환율로 제시하지 않습니다. 각 서비스의 현재 조건과 필요한 필드의 정의는 공식 문서에서 확인한 뒤 연동 범위를 정하세요.
