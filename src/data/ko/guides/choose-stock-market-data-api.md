## 서비스가 출력할 데이터부터 정의하기

사용자가 실제로 볼 내용이나 계산에 입력할 데이터를 먼저 적으세요. ‘주식 데이터’만으로는 범위가 너무 넓습니다. 자산 종류, 거래소, 종목 코드, 필요한 필드, 갱신 주기, 과거 데이터의 범위, 이용 대상을 구체적으로 정의해야 합니다. 한국과 미국 시장을 함께 다룬다면 각 시장에서 필요한 필드도 나누어 확인하세요.

예를 들어 ‘미국 상장 ETF의 일별 조정 종가와 현금 분배금을 장 마감 후 갱신하고, 백테스트를 위해 저장하며, 로그인한 개인 사용자에게 표시한다’고 적을 수 있습니다. 이 한 문장만으로도 일반적인 기능 목록보다 많은 선택 조건이 드러납니다.

## 기능표보다 먼저 이용권 확인하기

API에 접속할 수 있다고 해서 데이터를 저장·표시·재배포하거나 상업용 파생 상품에 사용할 권리까지 확보한 것은 아닙니다. 용도별로 근거를 따로 기록하세요.

| 사용 목적 | 확인할 근거 |
| --- | --- |
| 내부 분석 | 해당 구독에 적용되는 이용약관 |
| 지속적인 저장 | 보관 허용 조건 |
| 공개 화면 표시 | 표시 계약과 거래소 이용 조건 |
| 고객 데이터 내보내기 | 재배포 조건 |
| 파생 지표 생성 | 파생 데이터 관련 조항 |

공개된 요금제 설명이 모호하면 실제 사용 목적을 제시하고 영업 담당자에게 서면 답변을 받으세요. 호출 한도가 높거나 무료로 접근할 수 있다는 이유로 상업적 이용이 허용된다고 판단해서는 안 됩니다.

## 조정주가와 배당 날짜 의미 검증하기

분할, 배당, 상장폐지, 종목 코드 변경, 거래일 누락이 포함된 작은 기준 데이터 세트를 내려받으세요. 필요한 경우 미국 외 시장의 종목도 포함하고 다음 항목을 비교합니다.

- 원시 OHLC 필드와 조정 OHLC 필드
- 거래량의 분할 조정 여부
- 배당락일(ex-date), 기준일(record date), 지급일(pay date), 선언일(declaration date)
- 거래소와 시간대 식별자
- 데이터 수정과 재공시 반영 방식
- 종목 코드가 바뀌어도 유지되는 식별자

시험 중에는 공급자의 타임스탬프와 원본 응답을 보관하세요. 서로 다른 API가 같은 필드명을 사용하더라도 조정 규칙까지 같다는 뜻은 아닙니다.

yfinance로 먼저 확인한다면 [yfinance Adj Close와 MultiIndex 처리 사례](../yfinance-adj-close-auto-adjust-multiindex/)를 참고하세요. 가격을 비교하기 전에 `auto_adjust`와 컬럼 구조를 명시해야 하는 이유를 설명합니다. 분할·배당 반영 여부는 실제 관측 데이터로 별도로 검증해야 합니다.

한국 배당의 날짜 필드를 검토할 때는 [EODHD 한국 배당 지급일 누락과 SEIBRO 시장별 수집 사례](../eodhd-seibro-korean-dividend-source-selection/)를 함께 보세요. 날짜가 비어 있는 이유와 상장시장에 따라 수집 출처를 선택하는 경계를 구분할 수 있습니다.

## 재시도·백필을 포함한 호출량 계산하기

기본 호출량을 `symbols × resources × refreshes`로 추정한 뒤 최초 과거 데이터 수집(백필), 재시도, 오류 복구 작업, 개발 환경의 호출을 더하세요. 벌크 파일이나 묶음 요청이 비용 구조를 바꾸는지도 확인합니다. 운영과 비슷한 동시 요청 조건에서 응답 크기, 지연 시간, 압축, 페이지 처리, 호출 제한 동작을 측정하세요.

## 동일한 기준으로 후보 평가하기

공급자 가격을 보기 전에 이용권, 시장 범위, 정확성, 지연 시간, 복구 가능성, 지원, 비용의 중요도를 정하세요. 표시 가격이 낮아도 필수 이용권이나 종목 식별 조건을 만족하지 못하면 최종 후보로 삼기 어렵습니다.

두 후보에 같은 수용 시험을 수행하고 결과를 저장하세요. 공급자가 API 버전, 요금제, 가격 조정 정책을 바꾸면 같은 시험을 다시 실행합니다.

계산에 사용할 배당 데이터를 정리했다면 [GetBeta 배당 계산기](https://getbeta.app/tools/dividend-calculator)로 이어서 확인하세요.

공급자별 개요와 제약은 [EODHD](../../apis/eodhd/), [SEIBRO](../../apis/seibro/), [Massive (영문)](../../../apis/massive/), [Alpha Vantage (영문)](../../../apis/alpha-vantage/), [yfinance (영문)](../../../apis/yfinance/)에서 확인할 수 있습니다.

다음으로 [EODHD와 Massive 비교 (영문)](../../../compare/eodhd-vs-massive/) 또는 [EODHD와 Alpha Vantage 비교 (영문)](../../../compare/eodhd-vs-alpha-vantage/)를 읽어보세요. 분봉 데이터의 완전성을 확인하려면 [Massive 집계 봉 누락 사례 (영문)](../../../guides/massive-polygon-missing-aggregate-bars/)를 참고하세요.
