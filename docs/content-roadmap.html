01

프로바이더 추가 Top 10

우선순위 순. 1·2번은 조사한 모든 2026년 "best stock API" 라운드업에 등장한, 확신도가 가장 높은 두 개야.

1

Finnhub STOCK · FX · CRYPTO

"best free stock API"의 표준 답. 무료 티어 60 req/min + 무료 실시간 웹소켓이 무기야.

수요 신호 — 2026년 주식 API 라운드업 전부 등장, MCP 서버·Rust SDK 등 커뮤니티 생태계 활발

2

Twelve Data MULTI-ASSET

주식·FX·크립토·ETF를 하나의 깔끔한 시계열 API로. Alpha Vantage와 가장 많이 비교되는 상대. 무료 800 credits/day, 카드 불필요.

수요 신호 — Finnhub와 함께 라운드업 단골, Python 튜토리얼·FastAPI 템플릿 다수

3

CoinMarketCap CRYPTO

수요 신호 — CoinGecko 본인 비교표에서도 라이벌로 지목, 2026 크립토 API 가이드 단골

수요 신호 — "무료 LLM API 비교" 글에서 지연시간 1순위로 반복 추천

03

가이드 추가 Top 5

특정 프로바이더에 묶이지 않는 상시 수요 주제. 이미 커버한 페이지들(Stripe·Slack·GitHub·Twilio은 웹훅 비중이 큰 API)과 내부 링크로 엮기 좋아.

G1

웹훅 수신과 검증 (서명·재시도·멱등성)

전용 가이드 사이트(webhookguide.com)까지 있는 상시 주제. 서명 검증, 재시도/지수 백오프, 멱등 처리를 한 번에 다루면 기존 "retry/backoff" 가이드와도 이어져.

G2

OAuth 2.0 연동 (Authorization Code + PKCE)

거의 모든 API 플랫폼이 자체 가이드를 낼 만큼 볼륨이 큰 연동 주제. 사이트 독자층(API 레퍼런스를 찾는 개발자)과 정확히 겹쳐.

G3

API 인증 방식 비교 (API 키 vs OAuth 2.0 vs JWT)

전용 비교 가이드와 전문 사이트(Zuplo의 apikeys.guide)가 존재하는 주제. 기존 "API key safety" 가이드의 자연스러운 후속편이야.

G4

API 버저닝 전략 (URL vs 헤더, 폐기, Sunset 헤더)

"베스트 프랙티스" 검색의 단골. Stripe·GitHub의 헤더 버저닝 사례로, 이미 커버한 프로바이더와 구체적으로 연결할 수 있어.

G5

SDK vs raw HTTP 선택 기준수요 미검증

카탈로그의 모든 프로바이더가 SDK를 제공하니 소재는 충분해. 다만 이 주제는 이번 리서치에서 독립적으로 수요를 확인하지 못했어 — 만들기 전에 한 번 더 검증하고 들어가.

04

쓰기 전에 확인할 것

이 로드맵의 한계야. 전부 웹 검색 인덱스 기반이라, 페이지 작성 시점에 아래는 직접 확인하고 들어가.

  • Finnhub·Twelve Data 무료 티어 수치 — 2026년 10월에 읽은 제3자 라운드업 기준. 작성 전에 공식 가격 페이지로 재확인할 것.
  • Perplexity 제품명 — Sonar 은퇴(2026-09-27)·Agent API 대체는 제3자 마이그레이션 글 기반. docs.perplexity.ai에서 현재 명칭 확인 후 제목 확정.

  • 공식 문서 URL 전반 — 검색 결과에서 그대로 옮긴 주소들이야. 발행 전 스팟 체크 권장.
